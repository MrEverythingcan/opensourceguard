# OpenSourceGuard 完整功能基线

这份清单记录项目最初规划过的功能，后续版本必须以此为回归清单，不能因为重做界面或重打包而丢失入口。

## 版本回归记录

- **0.2.0**：本地诊断闭环、定位、复现测试、补丁、临时验证、安全和合规检查、GitHub 同仓库 Draft PR、三平台读取。
- **0.3.0**：跨平台和 fork 提交、依赖与环境隔离、Docker 路径、审计/费用/采纳反馈、六页面和报告导出、失败日志迭代。
- **0.4.0**：BM25、文件到函数的分层检索、排序融合、失误分析、ModelScope 上传/Space/脚本/界面。
- **0.5.0**：自治维护安全闭环、初学者仓库 Agent、部署安全边界和新的界面入口。
- **0.6.0**：GitHub/ModelScope Token 连接、账号仓库同步、确认式发布、开源缺项一键补齐，以及玻璃质感多页面工作台。

后续实现以“当前状态”列为准；只有通过代码、接口测试和演示验证后，才可以标记为“已实现”。
