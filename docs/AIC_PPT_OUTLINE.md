# AIC 答辩 PPT 大纲

1. 作品名称与一句话价值：让每一次开源修复都有证据。
2. Issue 积压和维护者痛点。
3. 目标用户与使用场景。
4. 总体架构和自动维护闭环。
5. AI 在理解、检索、生成和验证中的作用。
6. 混合代码检索：词法、BM25 风格、符号和路径证据。
7. 安全策略：验签、风险标签、沙箱、权限和人工接管。
8. Empty CSV 案例：基线失败、补丁通过、回归通过。
9. 任务队列与事件去重演示。
10. 开放成果：代码、测试、文档、许可证和资源清单。
11. 当前边界：本地验证完成，远程写入需要授权。
12. 后续计划：GitHub App、Docker、社区 Issue/PR 和反馈学习。
